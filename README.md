# Svenska

Небольшое статическое приложение для изучения разговорного шведского. Без бэкенда, базы данных и сборщика интерфейса. Интерфейс: Tailwind CSS 4 (CDN), vanilla JS modules, Lucide. Для озвучивания используется браузерный Web Speech API (голос sv-SE).

## Структура

- `index.html` — общий экран и навигация.
- `js/app.js` — маршрутизация по hash, выбор урока и этапа.
- `js/core.js` — загрузка JSON, озвучка, локальное сохранение прогресса.
- `js/modules/` — независимые экраны: каталог, теория и примеры, карточки, фразы, словарь, тест.
- `data/<slug>/` — **одна папка = одна тема**. Внутри `meta.json` и нужные разделы.
- `data/index.json` — автоматически генерируемый список всех тем.
- `scripts/sync-content.mjs` — генератор/валидатор каталога.

## Как добавить новую тему

1. Создайте папку `data/my-topic/`.
2. Добавьте `meta.json` с обязательными полями: `slug` (совпадает с именем папки), `title`, `group`, `groupTitle`, `outcome`. Дополнительно: `description`, `emoji`, `order`, `minutes`.
3. Добавьте нужные JSON-массивы: `theory.json`, `examples.json`, `cards.json`, `phrases.json`, `dictionary.json`, `quiz.json`. Можно начинать с части разделов: навигация строится только по существующим файлам.
4. Локально выполните `npm run content:sync` (Node.js 20+). При добавлении в `main` GitHub Action сам обновит `data/index.json`.

Важно: обычный статический сайт **не умеет получать список папок** по HTTP. Поэтому JavaScript загружает сгенерированный каталог. Новые темы автоматически появятся в приложении после обновления каталога, без правок JavaScript.

## Формат данных

`theory.json`:
```json
[{"title":"Правило","body":"Короткое объяснение","pattern":"Kan jag få…?","translation":"Можно мне…?"}]
```

`examples.json`:
```json
[{"sv":"Kan jag få en kaffe?","ru":"Можно кофе?","note":"Необязательная подсказка"}]
```

`cards.json`:
```json
[{"sv":"en kaffe","ru":"кофе","example":"En kaffe, tack."}]
```

`phrases.json`:
```json
[{"id":"coffee-1","text":"En kaffe, tack.","translation":"Кофе, пожалуйста.","words":[["En","en","артикль"],["kaffe","kaffe","кофе"],["tack","tack","пожалуйста"]]}]
```
В `words` можно добавить 4-й элемент (пояснение), 5-й (выражение) и 6-й (перевод выражения). Старые 40 фраз перенесены без потерь в соответствующие темы.

`dictionary.json`:
```json
[{"sv":"en kaffe","ru":"кофе","category":"Напитки","example":"En kaffe, tack."}]
```

`quiz.json`:
```json
[
 {"type":"choice","question":"Как сказать «кофе»?","options":["kaffe","vatten"],"answer":"kaffe"},
 {"type":"order","prompt":"Соберите «Кофе, пожалуйста»","words":["tack.","En","kaffe,"],"answer":"En kaffe, tack."}
]
```

Тест поддерживает выбор и составление предложений из слов. `answer` для `order` — полная правильная фраза. Внутри одного массива вопросы должны иметь уникальный смысл и один правильный ответ.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000/ (не открывать через `file://`, потому что ES modules и fetch JSON требуют HTTP).

```bash
npm run content:check
npm test
```

Прогресс, избранное и результаты тестов сохраняются в `localStorage` этого браузера, не синхронизируются между устройствами. Если в ОС отсутствует шведский голос, Web Speech может использовать голос с менее точным произношением.
